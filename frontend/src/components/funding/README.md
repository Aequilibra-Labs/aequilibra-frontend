# Funding Rates Comparison

A comprehensive platform for comparing funding rates across decentralized derivatives protocols.

## Features

- **Multi-Platform Support**: Compare funding rates from multiple DEXs
- **Real-time Data**: Live updates every 30 seconds
- **Interactive Selection**: Select/unselect platforms to customize your view
- **Advanced Filtering**: Search by asset name or platform
- **Sorting Options**: Sort by funding rate, asset name, or other metrics
- **Responsive Design**: Works on desktop and mobile devices

## Supported Platforms

### Currently Available
- **Hyperliquid** ⚡ - Leading perpetual futures DEX

### Planned Platforms
- **dYdX** 📈 - Decentralized derivatives
- **Paradex** 🚀 - Layer 3 derivatives

## Usage

1. **Select Platforms**: Use checkboxes to choose which platforms to compare
2. **Search Assets**: Filter by asset name or platform
3. **Sort Data**: Click column headers to sort by different metrics
4. **View Details**: See funding rates, annualized rates, and trading volumes

## Data Display

- **Funding Rate**: Current 8-hour funding rate
- **Annualized**: Approximate annual funding rate
- **24h Volume**: Trading volume in the last 24 hours
- **Direction**: Whether longs or shorts are paying funding

## Navigation

Access the funding comparison page via:
- Main navigation: "Funding Rates" link
- Direct URL: `/funding-comparison`

## Technical Details

- Built with Next.js and React
- Uses Radix UI components for accessibility
- Real-time data via custom hooks
- Responsive design with Tailwind CSS
- Dark mode support
